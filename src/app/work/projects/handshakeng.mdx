## Overview

HandshakeNG is a marketplace for buying and selling used phones, tablets, laptops, and watches in Lagos. Its core idea is trust: every device is inspected at a Checkpoint before it can be bought, which tackles the biggest worry in secondhand buying. I built the front end and the backend, from the listing pages to the APIs behind them.

## Key Features

- **Checkpoint inspection**: Devices are checked at a Checkpoint before they can be bought, so buyers aren't gambling on a stranger's word.
- **Browse and search**: Shoppers can browse by category and brand, search for a model, or request a model that isn't listed yet.

## Technologies Used

- **Django**: Backend, business logic, and server-rendered pages.
- **PostgreSQL**: Database for users, listings, and bids.
- **Cloudflare R2**: Image storage for banners and listing photos.
- **Render**: Hosting for the live app.
