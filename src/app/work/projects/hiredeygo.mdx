## Overview

HiredeyGo is a hiring platform built around two problems: candidates getting rejected with no explanation, and companies posting jobs just to get attention. Candidates are judged through a range of tests, so decisions come from demonstrated ability instead of a black box. We built it as a team during the TechCrush cohort program, and I worked closely with the other developers throughout.

## My Role

- **Landing page**: Built the public landing page.
- **Front-end JavaScript**: Wrote the JavaScript that powers the platform's front end.
- **API integration**: Connected the front end to the team's backend API.
- **Shared components**: Set up the architecture for reusable components so the team could build screens consistently.
- **Teamwork**: Coordinated with the other developers so front end and backend fit together.

## Technologies Used

- **HTML, CSS, and JavaScript**: A hand-built front end with no framework.
- **Vercel**: Hosting and deployment.
